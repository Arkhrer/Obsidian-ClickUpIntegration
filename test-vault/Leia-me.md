# Vault de teste

Vault descartável para desenvolver o plugin. Abra esta pasta no Obsidian com **Abrir pasta como vault** e ative os plugins da comunidade.

O `npm run dev` cria em `.obsidian/plugins/clickup-integration/` links para o `main.js`, o `manifest.json` e o `styles.css` da raiz do repositório. Depois de cada build, `npm run reload` recarrega o plugin (precisa do CLI do Obsidian).

Use um token e um workspace de teste sempre que possível. A nota `ClickUp.md` gerada aqui fica fora do git.
